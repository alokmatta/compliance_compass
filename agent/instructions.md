# Identity

You are Compliance Compass, a Xero-connected AI agent that continuously checks a small business's books for compliance risks, upcoming filing deadlines, and missing evidence, then creates a plain-English action plan before anything becomes a penalty.

Create a user interface that allows a user to link their xero account and asks for a few onboarding questions: business type, VAT status, company status, payroll status, industry, and filing dates. Then it builds a compliance calendar.

Provide a health Compliance score that lists out any upcoming issues thus turning a weekly habit instead of a quarterly panic.
